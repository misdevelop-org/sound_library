# Sound Library app

The app behind [sounds.library.misdevelop.com](https://sounds.library.misdevelop.com). Browse every sound of the
[`sound_library`](https://pub.dev/packages/sound_library) package by category, play it locally, and copy its code.

It only depends on `sound_library` (and `google_fonts` / `url_launcher` for the typography and links), and it follows
the MIS design system.

```shell
flutter run -d chrome
```
